## 2. 业务需求说明 (PRD)

### 业务背景
学员需在 15 分钟内向由架构师、产品经理与技术总监组成的评审团完整汇报《星辰智脑》项目，并完成 5 分钟高频技术追问与现场功能演示。

### 核心痛点
- 答辩时间分配头重脚轻，背景讲太久导致架构亮点与量化成果讲不完。
- 现场演示高度依赖外网与第三方模型 API，一旦网络抖动或限流即导致演示中断。
- 面对评委关于幻觉控制、成本核算、高并发瓶颈的追问缺乏结构化应答。

### 迭代目标
- 实现 15 分钟高分答辩结构规划与时间预算校验器（5 段黄金结构 + 评委评分维度模拟）。
- 实现可复现的现场演示脚本编排器：支持主链路实时运行 + 异常自动切换预录确定性快照，并生成答辩就绪度报告。

### 验收标准
- [x] 答辩规划器严格校验总时长为 15 分钟且核心架构+演示+指标占比 >= 65%。
- [x] 演示验收器覆盖知识问答溯源、多 Agent 高危 HITL 审批、Ragas 指标展示三个核心场景，且在主服务异常时无缝降级。
- [x] 纯 Python 离线运行，pytest 100% 通过。

### 非功能指标
- 演练脚本可直接作为答辩前 10 分钟的一键彩排验收工具。

## 3. 架构设计与交付清单

高分答辩的本质是一场 **受众导向的技术架构路演**：
1. **15 分钟黄金漏斗结构**：
   - **业务痛点与目标（2 分钟）**：一句话讲清给谁解决什么问题，目标量化指标是什么。
   - **核心架构与技术选型（4 分钟）**：展示分层架构图，重点讲清楚 *为什么* 选混合检索 + RRF + HITL 审批，而不是只会堆名词。
   - **端到端现场 Demo（4 分钟）**：演示 3 个最有冲击力的闭环——专有错误码精准溯源、超 2000 元报销触发主管审批恢复、越狱攻击安全拦截。
   - **量化验收与成本优化（3 分钟）**：甩出 Ragas 四维分、压测 P95/QPS 和 Token 降本 50%+ 的账单对比。
   - **真实踩坑与演进路线（2 分钟）**：讲 2 个真实排障案例（如 Nginx SSE 缓冲坑、LoRA 导出量化坑），瞬间拉满工程真实感。
2. **Demo 防翻车双活机制**：现场演示器优先调用实时后端，若超时或异常自动切至预先验证过的确定性 Snapshot 并标明降级模式，绝不冷场。
