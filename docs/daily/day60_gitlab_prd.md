## 2. 业务需求说明 (PRD)

### 业务背景
星辰智脑知识库承载公司财务报销、IT 运维、法务合同与产品 SLA 文档。业务要求回答必须有据可查、精准召回专有名词与同义问法，且在知识库无相关内容时明确拒答而非编造。

### 核心痛点
- 纯向量检索对工单号、错误码、制度编号召回率低。
- 纯关键词检索对口语化同义提问召回率为 0。
- 大模型回答缺乏原文引用角标，员工不敢直接采信用于财务或法务决策。

### 迭代目标
- 实现双路混合检索器：BM25 词法打分 + 稠密词袋/语义余弦相似度。
- 实现 RRF（Reciprocal Rank Fusion）融合与 Rerank 精排重打分。
- 实现带强制 `[doc_id]` 引用角标及置信度阈值拒答机制的 RAG 问答组装器。

### 验收标准
- [x] 混合检索在专有编号查询和同义语义查询上均能将目标文档排入 Top-2。
- [x] 当检索最高精排得分低于阈值时，明确返回'知识库未检索到依据'拒答提示，绝不瞎编。
- [x] 纯 Python 离线运行，pytest 100% 通过。

### 非功能指标
- 检索 1000 个切片响应时间 < 50ms。

## 3. 架构设计与交付清单

星辰智脑 RAG 引擎采用工业界标准的 **粗排双路召回 + RRF 融合 + 精排重排 + 溯源生成** 漏斗架构：
1. **BM25 词法路**：对中文做 2-gram + 英文/数字完整 Token 切分，对专有编号（如 `ERR_4291`、`SLA`）和精确制度条款拥有极高区分度。
2. **语义向量路**：结合领域同义词概念空间投影（生产环境无缝替换为 `bge-m3` / `text-embedding-v3`），解决'住酒店'与'住宿报销'的语义鸿沟。
3. **RRF 融合**：不直接把量纲不同的 BM25 分数和余弦相似度硬相加，而是按排名融合 `score = sum(1 / (60 + rank))`，鲁棒性极强。
4. **Rerank 精排与拒答门禁**：对 Top-K 候选做标题加权 + 覆盖率 + 连续短语匹配精排；若 Top-1 精排分低于 `min_score`，直接触发安全拒答，根治大模型一本正经胡说八道。
