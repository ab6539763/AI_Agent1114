## 2. 业务需求说明 (PRD)

### 业务背景
学员在正式投递冲刺前需经历贴近国内大厂真实标准的'技术一面 + 技术二面 + HR 面'三轮全真模拟，并获得客观的录用定级与可执行改进计划。

### 核心痛点
- 模拟面试反馈往往流于'感觉还行/再多准备准备'，缺乏量化维度与红线一票否决机制。
- 不知道距离 Strong Hire 还差哪几块拼图，复习没有优先级。
- 轻视 HR 面，在职业规划、薪资谈判与反问环节丢分。

### 迭代目标
- 实现大厂招聘委员会风格三轮加权打分器（含一票否决项检查：如编码红线或诚信/价值观红线）。
- 实现自动化 7 天靶向改进计划生成器：按薄弱维度优先级匹配对应刷题、ADR 补强与 HR 话术演练任务。

### 验收标准
- [x] 打分器准确计算综合得分与录用决策（`STRONG_HIRE` / `HIRE` / `NO_HIRE`），且对单项跌破红线（<60分）触发降级拦截。
- [x] 改进清单生成器能自动识别所有 `< 80` 分维度并按分数从低到高排布 7 天突击任务。
- [x] 纯 Python 离线运行，pytest 100% 通过。

### 非功能指标
- 输出的 Markdown 评估报告与改进清单可直接保存为个人求职复盘档案。

## 3. 架构设计与交付清单

模拟面试评估系统完整复刻国内一线大厂的 **Hiring Committee（招聘委员会）评分卡机制**：
1. **五大评估维度与权重**：
   - `coding_algo`（算法与 Python 工程手撕，25%）
   - `llm_rag_theory`（大模型/RAG/Agent 底层原理，20%）
   - `project_depth`（项目深挖与防问穿表现，25%）
   - `system_design`（高并发架构与容量估算，15%）
   - `hr_culture_fit`（沟通表达、动机稳定与团队契合，15%）
2. **木桶红线原则（Bar Raiser Gate）**：即便总分达到 80，只要任意单一核心维度低于 60 分（严重短板），判定降级为 `LEAN_NO_HIRE` / `NO_HIRE`。
3. **靶向 7 天整改引擎**：自动提取所有 `< 80` 分的薄弱维度，按分值升序（最痛先治）分配每日专项行动清单与验收标准。
